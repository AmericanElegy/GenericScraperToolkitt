# GenericScraperToolkitt

An operator-only table workbench: **Add source → Review/edit table → Download**.

The current work is on `codex/general-table-extraction`, local/preview only. It supports public website links, pasted text, Excel `.xlsx`, CSV/TSV, PDF and Word `.docx` with explicit coverage warnings and manual review. No customer accounts, billing or paid services.
